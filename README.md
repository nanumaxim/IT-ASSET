# IT Asset Registry — ระบบทะเบียนอุปกรณ์ไอที

เว็บแอปสำหรับบันทึกและค้นหาอุปกรณ์ไอทีขององค์กร (โน้ตบุ๊ก จอ เครื่องพิมพ์ สวิตช์ กล้องวงจรปิด ฯลฯ) แทนการใช้ไฟล์ Excel ที่ส่งต่อกันทางอีเมลจนหาข้อมูลไม่เจอและไม่รู้ว่าเวอร์ชันไหนล่าสุด ทำงานในเบราว์เซอร์ล้วน ไม่ต้องมีเซิร์ฟเวอร์หรือฐานข้อมูล

## ฟีเจอร์

- เพิ่ม / แก้ไข / ลบ ข้อมูลอุปกรณ์
- ค้นหาและกรองข้อมูลด้วยชื่อ ประเภท ผู้ถือครอง หรือสถานที่
- กรองหลายเงื่อนไขพร้อมกัน (ประเภท + สถานะ + ผู้ถือครอง)
- ตรวจสอบและเตือนเมื่อ Serial Number ซ้ำกัน
- หน้าสรุปภาพรวม แสดงจำนวนอุปกรณ์แยกตามประเภท/สถานะ
- Export ข้อมูลเป็น CSV/JSON สำหรับสำรองหรือย้ายจาก Excel เดิม
- Import ไฟล์ CSV/JSON กลับเข้าระบบ
- พิมพ์ / ส่งออกรายงานเป็น PDF
- บันทึกข้อมูลอัตโนมัติในเบราว์เซอร์ (localStorage) ไม่ต้องล็อกอิน

---

## วิธีเปิดใช้งาน

1. Clone หรือดาวน์โหลดโปรเจคนี้
2. เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (Chrome, Edge, Firefox) โดยตรง — ไม่ต้องติดตั้งอะไรเพิ่ม
3. เริ่มเพิ่มข้อมูลอุปกรณ์ได้ทันที ข้อมูลจะถูกบันทึกอัตโนมัติในเบราว์เซอร์ที่ใช้งาน
4. แนะนำให้กด **Export** เก็บไฟล์สำรองเป็นประจำ เนื่องจากข้อมูลผูกอยู่กับเบราว์เซอร์/เครื่องที่ใช้งานเท่านั้น

---

## เทคโนโลยีที่ใช้

- HTML / CSS / JavaScript (Vanilla, ไม่มี framework)
- Web Storage API (`localStorage`) สำหรับเก็บข้อมูล
- File API ของเบราว์เซอร์ สำหรับ Import/Export ไฟล์ CSV/JSON
- CSS `@media print` สำหรับจัดรูปแบบการพิมพ์/ส่งออก PDF
