# IT Asset Registry — ระบบทะเบียนอุปกรณ์ไอที

เว็บแอปสำหรับบันทึก ค้นหา และจัดการข้อมูลอุปกรณ์ไอทีขององค์กร (โน้ตบุ๊ก จอ เครื่องพิมพ์ สวิตช์ กล้องวงจรปิด ฯลฯ) ทำงานในเบราว์เซอร์ล้วน ไม่ต้องมีเซิร์ฟเวอร์หรือฐานข้อมูล

## ฟีเจอร์

- เพิ่มข้อมูลอุปกรณ์ใหม่ (ชื่ออุปกรณ์ ประเภท หมายเลขเครื่อง ผู้ถือครอง สถานะ)
- แก้ไขและลบข้อมูลอุปกรณ์ที่มีอยู่
- ค้นหาอุปกรณ์ด้วยชื่ออุปกรณ์ / หมายเลขเครื่อง / ผู้ถือครอง
- กรองรายการตามประเภทและสถานะ ใช้พร้อมกันได้
- แสดงจำนวนผลลัพธ์ที่พบเทียบกับจำนวนทั้งหมด
- บันทึกข้อมูลอัตโนมัติลง localStorage ทุกครั้งที่เพิ่ม/แก้ไข/ลบ ไม่ต้องกดบันทึกแยก ไม่ต้องล็อกอิน

---

## วิธีใช้งาน

1. เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (Chrome, Edge, Firefox) โดยตรง — ไม่ต้องติดตั้งอะไรเพิ่ม
2. กรอกฟอร์ม "เพิ่มอุปกรณ์ใหม่" ด้านบน แล้วกด **บันทึก**
3. ใช้ช่องค้นหาและตัวกรองประเภท/สถานะเหนือตาราง เพื่อหาอุปกรณ์ที่ต้องการ
4. กดปุ่ม ✏️ ในแถวรายการเพื่อแก้ไข หรือ 🗑️ เพื่อลบรายการ

---

## เทคโนโลยีที่ใช้

- HTML / CSS / JavaScript (Vanilla, ไม่มี framework, ไม่มีไลบรารีภายนอก)
- Web Storage API (`localStorage`) สำหรับเก็บข้อมูล

---

## ข้อจำกัดที่ควรรู้

- **ข้อมูลอยู่เฉพาะเบราว์เซอร์/เครื่องที่ใช้งานเท่านั้น** ยังไม่มีฟีเจอร์ export/import หรือสำรองข้อมูล หากล้าง cache เปลี่ยนเบราว์เซอร์ หรือเปลี่ยนเครื่อง ข้อมูลทั้งหมดจะหายและกู้คืนไม่ได้
- ยังไม่มีฟีเจอร์พิมพ์/ส่งออกรายงาน, หน้าสรุปภาพรวม, การเรียงคอลัมน์ในตาราง, การตรวจสอบ Serial Number ซ้ำ และปุ่มคัดลอกรายการ
- ไม่มีระบบยืนยันตัวตนหรือล็อกอิน ใครก็ตามที่เข้าถึงเครื่อง/เบราว์เซอร์นี้ได้ จะเห็นและแก้ไขข้อมูลทั้งหมดได้
- ไม่รองรับการใช้งานพร้อมกันหลายคนหรือหลายเครื่อง
